## 真机验收

已在一台 Android 16 真机（API 36）上实际执行：

- 终止进程、`adb install -r` 覆盖安装后数据仍在；`pm clear` 后为空状态。
- 当前值 = 初始值 + 事件 delta 之和：测试数据中 WaterWater 为 100 + 7 = 107，Debt 为 5 + (−6) = −1；把初始值从 0 改为 100 后当前值变为 107，7 条历史事件不变。
- 关闭允许负值后，主页减号被阻止并提示「当前值 0，再变化 −1 会小于 0」；编辑页把允许负值关掉会提示「当前值为 −1，请先调整到 0 或以上」并留在编辑页。
- 重置追加一条 RESET 事件并可撤销；菜单「撤销最新一条」→ 事件数 +1、值回到旧值；范围撤销 2 条 → 107 变 103、事件 7 变 9。
- 热力图分/时/日/周/月与三种指标可切换；分/时按本地时钟滚动分桶，日视图滚到最近、周/月柱状图月份标签不被裁切。
- 导出 JSON → `pm clear` → 替换导入空数据库：计数器/事件/标签数量恢复；再次导出与原文件除 `exportedAt` 外逐字段相等（Python 比对）。
- 合并导入同一文件：统计不变，提示「已跳过 N 条重复记录」。
- 负值冲突导入：选择「跳过」只新增合法计数器；选择「允许负值」新增计数器并显示负值。
- 全屏快速计数隐藏系统栏；音量键 +/+/- 后值 +1、本次 +1；步长长按菜单 +1/+5/+10/自定义均可用。
- 创建快捷方式弹出系统「添加到主屏幕」，接受后快捷方式名为计数器名；`count://quick/{id}` 深链可直接打开全屏计数。
- 深色模式切换立即生效并在重启后保留；浅色/深色下卡片层级、选中态和 Snackbar 对比度正常。
- 创建临时标签并绑定计数器，按该标签筛选后删除：标签从筛选行和卡片消失，筛选自动回到「全部」，计数器与事件不受影响。
- 一个计数器同时绑定多个标签：卡片与详情自动换行显示全部标签，筛选任一个均正常。
- 设置 → 外观 → 卡片大小切换「紧凑 / 标准 / 宽松」：主页卡片留白、当前值字号和加减按钮尺寸立即变化；紧凑档数值与加减按钮并排，按钮仍为 48dp，宽松档为 56dp；强制停止并重启后保持上次选择。
- 拖拽手柄长按可交换普通计数器顺序，强制停止后顺序保持；有标签筛选时手柄隐藏。
- 导出 CSV 成功，表头为 `counterId,counterName,eventId,timestamp,delta,source,note`，备注正确转义。
- `dumpsys package com.ltq.count` 没有请求任何 `android.permission.*`；唯一一条是 AndroidX 自动生成的 signature 级 `com.ltq.count.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`。Manifest 无 `INTERNET`。
- UI 无 emoji、无默认紫色、数字使用等宽数字；十位数值在主页/详情/全屏均不溢出。

### 黑屏回归

曾出现两次「只剩窗口背景」的黑屏：

1. 厂商 ROM 重新启动 Activity，但 `NavHost` 没有可绘制的目的地。加入配置变化后与 `RESUMED` 时的返回栈兜底：若没有任何 Compose 目的地就自动回主页。
2. 把 `orientation|screenSize` 放进 `configChanges` 后，传感器旋转只重建窗口、不重建 Activity，返回栈被清空且没有 `onResume`，兜底没有机会执行。移除这两个 flag，旋转恢复正常 Activity 重建，返回栈正常恢复。

验证方式：在临时测试入口把返回栈清到只剩图节点，复现空 `NavHost`，恢复逻辑会自动回主页；连续点击标题 20 次不会触发导航。真机切换字体大小、系统深浅色时 Activity 不重建，页面正常重排；横竖屏走正常重建，页面恢复。

## 已知限制

- 没有实现桌面小组件；`EventSource.WIDGET` 已预留。
- 数据库 schema 版本 1，暂无迁移；跨版本升级策略是导出 JSON 再导入。
- 事件列表一次性加载全部事件，未做分页；十万级事件下建议后续加分页/懒加载。
- 热力图在数据变化时重新计算；跨午夜或跨整分/整点后需要重新进入详情页或触发数据变化才会滚动窗口。
- 快捷方式依赖 Launcher 支持 `requestPinShortcut`；部分国产桌面可能仅支持系统弹窗或不支持。
- CSV 仅导出不导入。
- 自动化测试覆盖纯领域逻辑；UI/导入流程、SAF、快捷方式与音量键通过真机手工验收，仓库内没有 instrumentation 测试。
- 未配置 R8 混淆；release 签名通过本地 `keystore.properties` 提供，密钥不随仓库分发。
- 文本字段使用系统输入法；中文输入法的候选词提交依赖系统行为，未做自定义 IME。
