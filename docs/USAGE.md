# 使用说明

## 主页

- 顶部是置顶区，下面是普通计数器。编辑页可以把计数器设为置顶。
- 点卡片进入详情；长按卡片（或点右上角「更多」）打开菜单：编辑 / 置顶 / 标签 / 创建快捷方式 / 快速计数 / 删除。
- 普通区右侧有拖拽手柄：长按手柄上下拖动排序，松手后保存顺序。标签筛选状态下手柄隐藏，避免只对可见子集重排。
- 卡片右侧的 `−` / `+` 直接按当前步长加减。长按 `+` / `−` 弹出 `+1 / +5 / +10 / 自定义`，步长只在本次会话生效，不写回默认值。
- 每次数值变化后底部出现 Snackbar，可撤销刚发生的这一次操作。

## 新建与编辑

- 主页底部「新建计数器」。
- 可设置名称、初始值、默认步长、是否允许负值、置顶、标签。
- 关闭「允许负值」时，如果当前值已经小于 0，会提示先调整到 0 或以上，并留在编辑页。
- 修改初始值只改变基线，历史事件不变。

## 详情页

- 大号当前值，右上角「重置」是低强调文本按钮，点击后二次确认。
- 事件列表按时间倒序，显示时间、delta、来源、备注；可按时间范围、正负、是否有备注筛选。
- 点事件可编辑备注；长按事件可「撤销此条及其后所有事件」，确认后逐条追加反向事件。
- 详情页顶部是活动热力图，见下一节。

## 热力图

- 频率基准：次数 / 增量绝对值 / 净增量。
- 时间粒度：分 / 时 / 日 / 周 / 月，默认「日」。
- 分、时是最近 60 分钟 / 24 小时的滚动窗口，不随日历重置；日、周、月按本地日历分桶。
- 日视图是 52 周小方块，首屏滚到最近；周/月/分/时是柱状图。
- 净增量为负时用低饱和陶土色区分，不靠同色加深表达方向。
- 粒度选择是详情页的临时状态，退出再进入会回到「日」。

## 全屏快速计数

- 从卡片菜单「快速计数」或桌面快捷方式进入。
- 隐藏系统栏、保持屏幕常亮；大按钮 `+` / `−`，音量键也可以加减。
- 显示名称、当前值、本次会话增量；退出恢复系统栏并返回来源页。

## 桌面快捷方式

- 卡片菜单「创建快捷方式」会请求系统固定快捷方式，Intent 为 `count://quick/{id}`。
- 部分 Launcher 只支持系统弹窗或不支持 `requestPinShortcut`，以系统行为为准。

## 标签

- 编辑页或卡片菜单「标签」可以给计数器添加任意数量标签，标签只用于主页筛选，不做层级。
- 主页标签筛选行可横向滚动；末尾「管理标签」可以删除标签。
- 删除标签只删除标签与关联，不删除计数器和事件；如果正在按该标签筛选，会自动回到「全部」。

## 外观

- 设置 → 主题：跟随系统 / 浅色 / 深色。
- 设置 → 卡片大小：紧凑 / 标准 / 宽松，只影响主页卡片的留白、字号和按钮尺寸，不改变数据。
- 系统开启「移除动画」时，数值动画和热力图淡入会跳过。

## 数据

- 设置 → 导出 JSON：完整备份（计数器、初始值、事件、备注、标签）。
- 设置 → 导出 CSV：只用于表格查看，不能导入。
- 设置 → 导入 JSON：支持合并与替换，详见 [导入与导出](IMPORT_EXPORT.md)。
- 应用没有网络权限，也没有自动备份；卸载应用会删除本机数据，建议定期导出 JSON。

## 示例数据

仓库提供一份合成的长期使用示例 [samples/long-term-demo.json](../samples/long-term-demo.json)，可以直接导入，用来查看一年以上的热力图效果。导入方式见 [导入与导出](IMPORT_EXPORT.md#示例数据)。
